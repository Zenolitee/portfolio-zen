Project Athena creates scheduled raid announcements in Discord, lets guild members sign up from buttons on the announcement, tracks specialist slot limits, and gives server administrators a browser dashboard for schedules and rosters.

How it's built

Three packages: shared types and storage, the Discord bot (runs locally), and the web dashboard (runs on Vercel). The bot and the dashboard share state through Supabase.

Features

  • One-time and weekly recurring Node War rosters, with tier and weekday capacity presets.
  • Discord creation and editing wizards built from buttons, select menus and modals.
  • Roster groups (Mainball/FFA, Defense, Zerker, Shai, Bench, custom) with automatic overflow to Bench.
  • Guild Boss Raid scheduling with a configurable boss order.
  • A minute-based scheduler with restart recovery and duplicate-post prevention.
  • Discord OAuth dashboard login; JSON-file or Supabase storage.
