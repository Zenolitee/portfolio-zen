asciify-ps

A Windows 2000-style desktop app that turns images into coloured ASCII art with a live preview.

asciify-ps is a desktop front end for the asciify-them rendering library. Open or drag in an image, adjust it, and watch the coloured ASCII version redraw as you go.

What's new in 1.1

  • A Windows 2000-inspired classic interface: beveled buttons, framed settings, tabs and a dark ASCII canvas.
  • Brightness, contrast, gamma and saturation sliders that update the preview live.
  • Adjustable edge sensitivity for stronger or subtler outlines.
  • Your own character ramp, from sparse to dense.
  • Presets: save the current settings to a JSON file and load them for the next image.

Everything else

  • Five built-in character sets, including braille for the smoothest gradients.
  • Colour or black and white, 20 to 300 columns wide.
  • Copy to the clipboard, or save as .txt, .ps1 (PowerShell) or .cmd.
  • Ships as a single .exe: no install, no console window.
